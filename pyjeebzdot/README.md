# pyjeebz.com

Personal site for Mujeeb. Built with Astro, React, and TailwindCSS.

## Running Locally

Requires Node.js v22.12.0+.

```bash
npm install
npm run dev
```

## Commands

| Command                 | Action                                       |
| :---------------------- | :------------------------------------------- |
| `npm install`           | Install dependencies                         |
| `npm run dev`           | Start dev server at `localhost:4321`         |
| `npm run build`         | Generate OG images and build to `./dist/`    |
| `npm run preview`       | Preview production build locally             |
| `npm run check`         | Run `astro check` type diagnostics           |
| `npm run generate:og`   | Regenerate OG images via satori              |
| `npm run generate:icons`| Regenerate PWA icons from `favicon.svg`      |
